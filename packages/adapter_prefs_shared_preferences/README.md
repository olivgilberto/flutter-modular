# adapter_prefs_shared_preferences

As preferências não sensíveis do usuário (tema e idioma), com
shared_preferences.

- **Contém:** `SharedPreferencesAppPreferences` (porta `AppPreferences`).
- **Nunca contém:** tokens, dados pessoais ou de negócio (vão para o
  armazenamento seguro ou para o banco criptografado de um módulo).
